# ecopolis-group/.github

Zweck: Organisationsweite Standarddateien (Community Health Files) der Organisation ecopolis-group.

Lizenz: proprietär, alle Rechte vorbehalten, keine offene Lizenz.

Arbeitsweise: Ab jetzt nur Branch plus Pull Request. Mergen darf nur Michi.

Sichtbarkeit: öffentlich. GitHub verlangt ein öffentliches Repository namens `.github` für organisationsweite Vorgabedateien, siehe [Creating a default community health file](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file). Dieses Repository enthält keine vertraulichen Projektinhalte.

## Herkunft der Standard-PR-Vorlage

Die Datei [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) ist inhaltsgleich mit [`.github/pull_request_template.md`](https://github.com/ecopolis-group/ecopolis.root/blob/docs/pr-vorlage-standard/.github/pull_request_template.md) in [ecopolis.root](https://github.com/ecopolis-group/ecopolis.root). Fachliche Grundlage ist [PR 217](https://github.com/ecopolis-group/ecopolis.root/pull/217), Datei [`docs/projekt-pr-approval.md`](https://github.com/ecopolis-group/ecopolis.root/blob/docs/projekt-pr-approval/docs/projekt-pr-approval.md) auf dem Branch `docs/projekt-pr-approval`, Entscheidung E27 (Abnahmekriterien Pflicht). Auftrag: Michi, Voice 19.11.2026, 16:05 Europe/Berlin, an Juli.

GitHub verwendet diese Datei als Vorgabe für jedes Repository der Organisation, das keine eigene Pull-Request-Vorlage hat. Die Vorlage wird erst wirksam, nachdem Michi sie hier und die Kopie in ecopolis.root gemergt hat.

Erläuterung in root: [`docs/standard-pr-vorlage.md`](https://github.com/ecopolis-group/ecopolis.root/blob/docs/pr-vorlage-standard/docs/standard-pr-vorlage.md) (Branch-Link, bis der Folge-PR gemergt ist).
